title: Embedding Hybrid Systems into Continuous Latent Vector Fields

abstract: This work proves that an $n$-dimensional hybrid system can be embedded into
  an $m$-dimensional Euclidean space equipped with a continuous vector field on its
  embedded image whenever $m>2n$. This result suggests that an <em>intrinsically</em>
  discontinuous hybrid system generically admits a continuous <em>extrinsic</em> representation
  that is well-posed for differentiable optimization. Building on this existence theorem,
  we show that a latent Neural ODE with consistency loss in both the latent and state
  space can accurately recover the flow of hybrid systems. Extensive experiments suggest
  the proposed method outperforms the existing method in learning hybrid systems with
  varying geometries from only time series data.
