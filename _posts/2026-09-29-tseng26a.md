title: "$L^3$: Large Lookup Layers"
openreview: A7LiBHEsOo
abstract: 'Modern sparse language models typically achieve sparsity through Mixture-of-Experts
  (MoE) layers, which dynamically route tokens to dense MLP "experts." However, dynamic
  hard routing has a number of drawbacks, such as potentially poor hardware efficiency
  and needing auxiliary losses for stable training. In contrast, the tokenizer embedding
  table, which is natively sparse, largely avoids these issues by selecting a single
  embedding per token at the cost of not having contextual information. In this work,
  we introduce the Large Lookup Layer (L3), which generalizes embedding tables to
  model decoder layers as a means of further scaling sparsity. L3 layers use static
  token-based routing to aggregate a <em>set</em> of learned embeddings per token
  in a <em>context-dependent way</em>, allowing the model to efficiently balance memory
  and compute by caching information in embeddings. L3 has two main components: (1)
  a systems-friendly architecture that allows for fast training and CPU-offloaded
  inference with no overhead, and (2) an information-theoretic embedding allocation
  algorithm that effectively balances speed and quality. We empirically test L3 by
  training transformers with up to 2.6B active parameters and find that L3 strongly
  outperforms both dense models and iso-sparse MoEs in both language modeling and
  downstream tasks.'
