title: Investigating Memory in Model-Free RL with POPGym Arcade

abstract: How should we analyze memory in deep RL? We introduce tools for analyzing
  policies under partial observability and revealing how agents use memory to make
  decisions. To utilize these tools, we present POPGym Arcade, a collection of Atari-inspired,
  hardware-accelerated environments sharing a single observation and action space.
  Each environment provides fully and partially observable variants, enabling counterfactual
  studies on observability. We find that controlled studies are necessary for fair
  comparisons and identify a pathology where value functions smear credit over irrelevant
  history. Using this pathology, we demonstrate how out-of-distribution scenarios
  can contaminate memory, perturbing the policy far into the future.
