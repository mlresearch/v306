title: Breaking the Reference Bottleneck via Learning to Rewrite Conversational Queries
  without Gold Reference Passages
openreview: QPRQHxrFLQ
abstract: 'Conversational query reformulation (CQR) has become indispensable for improving
  retrieval in dialogue-based applications. However, existing approaches typically
  rely on reference passages for optimization, which are <b>impractical</b> to acquire
  in real-world scenarios. To address this limitation, we introduce a novel <b>reference-free</b>
  preference optimization framework <b><em>DualReform</em></b> that generates <b>pseudo
  reference passages</b> from <b>commonly-encountered</b> conversational datasets
  containing only queries and responses. DualReform attains this goal through two
  key innovations: (1) <b>response-based inference</b>, where responses serve as proxies
  to infer pseudo reference passages, and (2) <b>response refinement via the dual-role
  of CQR</b>, where a CQR model refines responses based on the shared objectives between
  response refinement and CQR. Despite not relying on reference passages, <b><em>DualReform</em></b>
  achieves 96.9–99.1% of the retrieval accuracy attainable only with reference passages
  and surpasses the state-of-the-art method by up to 31.6%.'
