abstract: 'Parallelizing code for <b>irregular data structures</b> (sparse graphs,
  unbalanced trees, non-uniform meshes) is notoriously hard, and current LLMs fail
  catastrophically on such tasks, generating code riddled with race conditions, deadlocks,
  and poor scaling. We address this with <b>ParEVO</b>, a framework for synthesizing
  high-performance parallel algorithms for irregular data, built on three contributions:
  the <b>Parlay-Instruct Corpus</b> of 13,820 tasks generated via a "Critic-Refine"
  pipeline that filters for empirically performant uses of Work-Span primitives; specialized
  <b>DeepSeek</b>, <b>Qwen</b>, and <b>Gemini</b> models fine-tuned to the semantics
  of the ParlayLib library; and an <b>Evolutionary Coding Agent (ECA)</b> that repairs
  the "last mile" of correctness using compiler and profiler feedback. On the ParEval
  benchmark, ParEVO achieves an average <b>107x speedup</b> and a <b>13.6x speedup</b>
  on highly complex irregular graph problems, outperforming commercial models like
  GPT-5-Thinking and Gemini-3-Pro, while matching expert <em>human-written</em> baselines
  and reaching up to a <b>4.1x speedup</b> on kernels such as Maximal Independent
  Set. This demonstrates that AI-driven agents can effectively navigate the complex
  landscape of high-performance computing. Source code and datasets are available
  at https://github.com/WildAlg/ParEVO.'
