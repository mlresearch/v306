title: Understanding the Parameter Space Volume of Transformers Encoding Boolean Functions
openreview: rUZVcnQjYW
abstract: Transformers consistently fail to learn certain simple functions that are
  provably expressible with specific parameter settings. This gap between <em>learnability</em>
  and <em>expressivity</em> is particularly prominent for sensitive functions—functions
  whose output is likely to change if a single bit of the input is flipped—for example,
  Parity. While prior work has established that transformers exhibit a bias toward
  functions with low average sensitivity, the precise mechanism underlying this bias
  remains poorly understood. To shed light on this phenomenon, we study volume in
  transformer parameter space. We show that sensitive functions—even when representable—occupy
  a vanishingly small region that random initialization is very likely to miss. Specifically,
  we shift the focus from average sensitivity to the full sensitivity profile—the
  distribution of sensitivity values across all inputs—and prove that randomly initialized
  transformers almost surely compute functions which have low-sensitivity strings.
  Consequently, any function that lacks such strings is provably unlearnable.
